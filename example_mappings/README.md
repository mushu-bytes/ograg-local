# Example Mappings

This paper contains an example ontology mapping using the low level ontology for CLBP without additional ontology descriptions. Chunks are stored in chunks/, with the corresponding mappings stored in ontology_mappings/. The source pdf is tarabeih2022.pdf.

These examples were intentionally chosen to show mapping errors and/or hallucinations when the ontological schema used by ograg does not match the document chunks. This is included solely as a aid for the submission to IEEE CAI.
